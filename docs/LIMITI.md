# Limiti – Investigative Leads Generator

Documento obbligatorio. Estende i limiti di investigative-explorer-dvns.

## Limiti metodologici (vincolanti)
1. Una pista è solo un segnale quantitativo. Non è prova di nulla.
2. Le omonimie non vengono risolte.
3. I perimetri contabili restano sempre separati.
4. L'assenza di una pista non è un risultato.
5. La copertura dei dati di partenza è parziale per costruzione (vedi LIMITI.md dell'Explorer).
6. Nessuna regola può essere attivata senza test contro falsi positivi e validazione manuale di almeno 20 piste.

## Trattamento delle persone
Identico a quello dell'Explorer: solo ruolo pubblico documentato, nessun arricchimento esterno, diritto di segnalazione via issue.

## Regola di esposizione
Ogni pista deve contenere: regola, fonti precise, periodo, disclaimer obbligatorio e sezione "Cosa non si può affermare".
In assenza di anche uno solo di questi elementi la pista non viene generata.
